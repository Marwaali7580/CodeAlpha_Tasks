# CodeAlpha_DiseasePrediction
Breast cancer prediction using machine learning
## Objectives
Predict whether a tumour is cancerous using patient medical data
## Dataset
Breast Cancer Wisconsin dataset (UCI),569 patients,30 features.
## Models Used 
logistic Regression
SVM
Random Forest
## Results
Model                 Accuracy
Logistic Regression      95.6%
SVM                      94.7%
Random Forest            96.5% (best)

Random forest (Cancer class): Precision 0.98, Recall 0.93, F1-score 0.95
## Tools 
Python, scikit-learn, Google Colab
## How to Run?
open 'Disease_Prediction.ipynb' in Google Colab and click Runtime > Run all.
